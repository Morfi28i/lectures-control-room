# غرفة تحكم المحاضرات

لوحة تحكم في أوتوميشن المحاضرات: بتسحب الجديد من الدرايف وترتّبه، وبترفع على الدرايف، وبتفحص التطابق، وبتعرض كل المحاضرات والملفات اللي اتعملت لكل واحدة. ومنها كمان بتوقف الطيار الآلي وبتشغّله، وبتبعتله طلبات، وبتعدّل الثوابت.

- على الماك: `node server.mjs` وبعدها افتح http://localhost:4545
- النسخة المستضافة على GitHub Pages بتتوصل بالسيرفر اللي على نفس الماك. من أي جهاز تاني هتعرض الشكل بس، من غير بيانات.
